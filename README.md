# Pocket Guitar

A browser guitar practice app in one HTML file (`index.html`). Open it in a browser; nothing to install.

- **Practice**: six-string tab timeline or a vertical falling-notes mode. Left hand holds chords, right hand plucks strings or strums. Timing, string and chord are scored.
- **Tab input**: write tabs as text (`5-3`, `D`/`U` strums, `h`/`p`/`s` techniques, repeats), or scan a tab screenshot. Scanning runs in the browser.
- **Library**: import score images into collections.
- **Free play** and **song sheet** (paste a chord chart and practice it).

Keys: `H J K L ; '` pluck strings, `Space` strums down, `N` strums up.

Originally built as a claude.ai artifact: https://claude.ai/artifact/8nuPjWXUnc8VWyKeMEBnq8
Opened outside claude.ai, the library is saved in the browser's local storage.
